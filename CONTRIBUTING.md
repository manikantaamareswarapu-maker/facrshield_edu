Contributing
============

Thanks for your interest in contributing to FactShield. Please follow these quick guidelines:

- Fork the repository and create a feature branch for your changes.
- Keep changes focused and add tests for new functionality under `tests/`.
- Follow the code style: run `flake8` and fix issues before submitting.
- Open a pull request describing the change and link any relevant issues.

Development
-----------

1. Create a virtual environment and install dev dependencies:

```bash
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
```

2. Run tests locally:

```bash
pytest -q
```

Thank you — contributions are welcome!
